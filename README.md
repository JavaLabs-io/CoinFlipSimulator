# CoinFlipSimulator

A simple Java program that simulates flipping a coin and randomly returns Heads or Tails.

## Why I Built This

I built this project as a quick way to practice Java fundamentals and random number generation. It's a simple simulation, but it demonstrates how randomness can be used to model real-world events.

## Features

- Simulates a coin flip
- Randomly generates Heads or Tails
- Simple console-based output
